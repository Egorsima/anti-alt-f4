# Anti Alt+F4 (тестовая версия)

Запустил `anti-alt-f4.exe` — приложение висит в трее.
Нажал Alt+F4 — комбинация блокируется, по центру экрана появляется окно с репликой (1 → 9).

Реплики 1–9 показываются по очереди, каждая со звуком уведомления (чем дальше — тем злее).
На **10-е нажатие** запускается скример:

- на весь экран (все мониторы) — своя картинка `assets/frames.bin` (лицо из темноты), без рамок и кнопок;
- анимация без криков: лицо дышит, дёргается, глитчит (10 заранее посчитанных кадров);
- по центру по одной букве печатается текст под тяжёлые удары (низкий «в груди» удар каждый третий,
  короткие клики между ними) — с тихим жутким эмбиентом леса на фоне (ветер, далёкий скрип);
- текст рисуется на своей подложке с ручным переносом строк, поэтому не ломается и не вылезает;
- звук всех остальных приложений глушится на время скримера (Discord в том числе), после — возвращается;
- клавиатура, мышь и переключение окон заблокированы, курсор заморожен и не виден;
- после 4-й строки — белая вспышка и «ангельский» звук: возрождение, счётчик попыток начинается заново.

Ассеты (звук/кадры) готовятся офлайн скриптами:

```bash
python3 tools/build_sfx.py      # assets/sfx/*.wav из библиотеки uisfx (MIT)
python3 tools/build_frames.py   # assets/frames.bin из assets/screamer_source.png
```

Ограничение: `Ctrl+Alt+Del` перехватить нельзя — это защита самой Windows.

- Выход: иконка в трее → «Выход» (двойной клик по иконке — показать окно).
- В трее есть «Звук» (вкл/выкл) и «Проверить скример» (запустить скример вручную).
- Закрытие окна крестиком не убивает приложение — оно просто прячется обратно в трей.
- Лог пишется в `%LOCALAPPDATA%\AntiAltF4\app.log`.

## Сборка

```bash
pip install -r requirements.txt pyinstaller
python make_icon.py
pyinstaller --onefile --noconsole --name anti-alt-f4 --icon icon.ico \
  --add-data "assets/frames.bin;assets" --add-data "assets/sfx;assets/sfx" anti_alt_f4.py
```

exe также собирается автоматически в GitHub Actions (`.github/workflows/build.yml`) и кладётся в Releases по тегу `v*`.
