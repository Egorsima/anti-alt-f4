# Anti Alt+F4 (тестовая версия)

Запустил `anti-alt-f4.exe` — приложение висит в трее.
Нажал Alt+F4 — комбинация блокируется, по центру экрана появляется окно с репликой (1 → 9).

Реплики 1–9 показываются по очереди, каждая со звуком уведомления (чем дальше — тем злее).
На **10-е нажатие** запускается скример:

- на весь экран (все мониторы) — картинка `assets/screamer.jpg`, без рамок и кнопок, поверх всех окон;
- по центру по одной букве «по-старинному» печатается текст, со звуком печатной машинки;
- звук всех остальных приложений глушится на время скримера, после — возвращается;
- клавиатура и мышь заблокированы (курсор спрятан и заморожен), закрыть нечем;
- допечатав 4 строки, скример исчезает, звук и ввод возвращаются, счётчик попыток начинается заново.

Ограничение: `Ctrl+Alt+Del` перехватить нельзя — это защита самой Windows.

- Выход: иконка в трее → «Выход» (двойной клик по иконке — показать окно).
- В трее есть «Звук» (вкл/выкл) и «Проверить скример» (запустить скример вручную).
- Закрытие окна крестиком не убивает приложение — оно просто прячется обратно в трей.
- Лог пишется в `%LOCALAPPDATA%\AntiAltF4\app.log`.

## Сборка

```bash
pip install -r requirements.txt pyinstaller
python make_icon.py
pyinstaller --onefile --noconsole --name anti-alt-f4 --icon icon.ico --add-data "assets/screamer.jpg;assets" anti_alt_f4.py
```

exe также собирается автоматически в GitHub Actions (`.github/workflows/build.yml`) и кладётся в Releases по тегу `v*`.
