# Anti Alt+F4 (тестовая версия)

Запустил `anti-alt-f4.exe` — приложение висит в трее.
Нажал Alt+F4 — комбинация блокируется, по центру экрана появляется окно с репликой (1 → 9, дальше остаётся 9-я).

- Выход: иконка в трее → «Выход» (или двойной клик по иконке — показать окно).
- Закрытие окна крестиком не убивает приложение — оно просто прячется обратно в трей.

## Сборка

```bash
pip install -r requirements.txt pyinstaller
python make_icon.py
pyinstaller --onefile --noconsole --name anti-alt-f4 --icon icon.ico anti_alt_f4.py
```

exe также собирается автоматически в GitHub Actions (`.github/workflows/build.yml`) и кладётся в Releases.
