# Ассеты

## Звук
Сэмплы взяты из открытой библиотеки **uisfx** v0.4.0
(https://github.com/romainsimon/uisfx, MIT License), обработаны скриптом
`tools/build_sfx.py` (ресемпл 22050 Гц/моно/16 бит, нормализация, петля фона,
слои для «ангела», набор уведомлений 1–9).

## Изображение скримера
Исходник `assets/screamer_source.png` — сгенерирован для проекта.
Кадры анимации собирает `tools/build_frames.py` в `assets/frames.bin`.
